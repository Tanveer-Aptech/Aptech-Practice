                                      --------------Individual Project Details--------------------

"BMI Calculator"

This program is used to calculate Body mass index of a person made with HTML CSS and JavaScript with good usage of loops and math. Floor type logic,
this also uses basic conversion skills and have a different section of standard and imperial units

this web app also contains a slider made with JavaScript and styled with CSS

Overall a good experience to use this calculator for day to day BMI calculation purposes


"Counter Program"

this program is a simple counter program that adds +1 or deduct -1 from the original value of the counter itself

made via HTML CSS and JavaScript with good use of functions and i++ iterations with loops


"Stop Watch Program"
this program is a simple stop watch program also made via HTML CSS and JavaScript, use to observe time elapsed 

included 3 buttons of "Start" "Stop" "Reset" with their own functions and proper implemented logic

used math. Floor and and time unit conversions to show HH:MM:SS:MS altogether in a for a digital stop watch

"Temperature Calculator Program"

this program is just a simple Temperature Conversion program which converts Celsius to Fahrenheit and Vice-Versa

used basic functions and formulas of converting to both units flawlessly 

made via HTML CSS and JavaScript just a cool little project

"Dice Roller Program"

A casual dice rolling program for table top utilities for table top games.
made with HTML CSS and JavaScript 
this project was initially made to have a better grasp of JavaScript with more array logic while using push and join methods to make it more fluid
